TaaOS - The Advanced Agentic OS
===============================

Welcome to TaaOS!

This media contains a bootable live system of TaaOS.
You can boot from this drive to try TaaOS without installing it,
or run the installer to set it up on your hard drive.

Resources:
- GitHub: https://github.com/taasezer/TaaOS
- Documentation: /usr/share/doc/taaos/

Enjoy your new operating system!
